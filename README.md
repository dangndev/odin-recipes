# odin-recipes
An Odin Project assignment on HTML 5 
involving creating 3 recipes.

 Foundations: 
HTML Basics Project Overview.
 This repository contains my completed solutions for the HTML 
Basics project, part of [The Odin Project's] 
(https://www.theodinproject.com/).

 Foundations Curriculum.
 The primary goal of this project 
was to establish a solid foundation in core 
web technology by building structured, 
semantic web pages using pure HTML from 
scratch—without relying on frameworks, 
templates, or graphical editors. By 
completing these exercises, I built a series 
of functional web pages that follow modern 
web standards and accessibility practices.
 
Skills Demonstrated.
 Upon completing this module and repository, I have demonstrated 
proficiency in the following core 
competencies:
 Semantic HTML 
Markup:Structuring web content logically 
using meaningful HTML tags (`<header>`) Text 
Formatting & Hierarchy:Creating clear visual 
and document structure using proper heading 
hierarchies (`<h1>` through `<h6>`), 
paragraphs (`<p>`), strong emphasis 
(`<strong>`, and inline elements.

 Document Architecture:
Constructing valid HTML5 document boilerplates 
complete with correct doctype declarations
 (`<!DOCTYPE html>`), language attributes,
 and required `<head>` metadata.

 Hyperlinks & Navigation:
Creating absolute and relative links (`<a>`) to 
connect local internal pages, link out to 
external resources, and open links in new 
browser tabs safely using `rel="noopener 
noreferrer"`.

 Working with Media:
 Embedding and optimizing images (`<img>`) using
 correct file paths (both relative and absolute), 
setting accessible `alt` text for screen 
readers, and maintaining proper aspect 
ratios.

 List Management:
 Constructing organized content using ordered
 (`<ol>`), unordered (`<ul>`), and nested lists.

 Project Organization & Version Control:
 Structuring web project files cleanly with standard 
folder structures (`/images`, `/pages`, 
`index.html`) and tracking changes using Git 
and GitHub.
